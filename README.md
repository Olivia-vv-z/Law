# 聊天记录截图排序工具

把微信 / QQ 聊天截图按**图中对话时间**从早到晚自动排序归档。一次运行生成一个《日期-当事人》文件夹，不同案件的截图互不干扰。

专为整理诉讼证据材料设计：截图扔进去，出来就是按时间线排好的文件夹。

---

## 快速开始

1. 把截图放进 `输入` 文件夹（可按当事人建子文件夹）
2. 双击 `排序.bat`
3. 到 `输出\2026-11-25-张三\` 取结果

结果文件名形如 `001_2024-07-17_0910.png`，**序号就是对话时间顺序**。

## 目录结构

```
聊天记录排序工具\
├── 排序.bat                双击运行入口
├── 聊天记录排序.py          主脚本：时间解析、排序、归档
├── ocr_worker.ps1          OCR 工作进程（调用 Windows 内置识别引擎）
├── README.md              本文档
├── 输入\                  放截图
│   ├── 张三\              子文件夹名 = 当事人
│   └── 李四\
└── 输出\
    └── 2026-11-25-张三\
        ├── 001_2024-07-17_0910.png
        ├── 002_2024-07-30_1057.png
        ├── ...
        ├── 待核对\         未能识别时间的图
        └── 历史\           同一天重复运行时，上次结果自动存这里
```

**输入可以两种摆法**：

- 单案：截图直接放 `输入\`，输出归入「日期-未分类」，或用 `--case 张三` 指定
- 多案：`输入\张三\`、`输入\李四\` 各放各的，一次跑完全部归档，互不混

## 命令行参数

| 参数 | 说明 |
|------|------|
| `--case 姓名` | 指定当事人，全部截图归入一个《日期-姓名》文件夹 |
| `--date 2026-11-20` | 指定文件夹名中的日期（默认运行当天） |
| `--input 路径` | 指定截图目录（默认 `输入\`） |
| `--output 路径` | 指定结果根目录（默认 `输出\`） |
| `--dry-run` | 只预览排序结果，不复制任何文件 |
| `--move` | 移动原件（默认复制，原件不动） |
| `--no-ocr` | 跳过识别，只按文件修改时间排序 |
| `--keep-old` | 保留案件目录上次结果（默认移入 `历史\`） |

示例：

```bat
python 聊天记录排序.py --case 夏晶男 --dry-run
python 聊天记录排序.py --input "D:\案件\源" --output "D:\案件\排序后" --case 夏晶男
```

## 识别的时间格式

| 类型 | 示例 |
|------|------|
| 完整日期 | `2024年12月17日 12:08` |
| 月日 | `8月10日 11:18`、`8/10 11:18` |
| 相对日期 | `昨天 18:40`、`前天 09:12`、`星期三 21:35`、`周三 21:35` |
| 时段 + 时间 | `上午 10:23`、`下午 3:45`、`晚上 9:12`、`凌晨 1:30`、`中午 12:20` |
| 纯时间 | `21:35`（微信"当天"的分隔条） |

**取哪一行作为该图的时间**：图内最靠上的那条时间分隔条（即该屏对话的起点）。含日期的行优先；只有纯时间的行才使用，且自动排除手机状态栏区域的当前时间。

**年份如何确定**：图里写了年就按写的；只写月日时，以截图文件的日期为基准，若推算出的日期晚于截图日期 3 天以上，自动往前推一年（避免把去年的记录算成明年）。

**跨天校正**：纯时间分隔条若算出的时刻晚于截图时刻，自动回退一天。

## 工作原理

```
截图 → 放大 2 倍（提升小字识别率）→ 超长图分块 → Windows OCR
     → 每行文本 + 纵向坐标 → 筛选时间分隔条 → 解析时间 → 排序 → 复制重命名
```

几个关键设计：

- **零第三方依赖**：OCR 用 Windows 10/11 自带的 `Windows.Media.Ocr`（zh-Hans-CN），不装 Tesseract、不联网
- **2 倍双三次放大**：微信时间条是浅灰小字，放大后识别率明显提升（实测 3 倍反而退化）
- **长截图分块**：超过 1600px 高的图按块识别（重叠 120px 防切断），避免整图缩放丢字
- **双通道重试**：第一遍识别不出的图，自动用「灰度 + 对比度拉伸」增强模式再来一遍，仍失败才进 `待核对`
- **坐标判位**：用每行文字的纵坐标区分"对话时间分隔条"和"手机状态栏时间"，不是靠文字内容猜

## 环境要求

- Windows 10 / 11（需要系统已安装中文简体语言包，绝大多数中文系统自带）
- Python 3.8 及以上，且在 PATH 中
- 无需安装任何 Python 第三方库

检查 OCR 语言包是否就绪：

```powershell
[Windows.Media.Ocr.OcrEngine, Windows.Foundation, ContentType=WindowsRuntime]::AvailableRecognizerLanguages
```

能看到 `zh-Hans-CN` 即可用。

---

## 使用限制

1. **OCR 可能误识**，尤其时间条字浅、被表情/图片遮挡、分辨率过低的截图。运行时控制台会打印每张图识别到的**时间原文**，这就是核对依据，建议抽查
2. 同一分钟内的多张截图按原文件名顺序排（截图通常按对话先后截，这个次序一般是对的）
3. 一张图横跨多个日期时，取该图**最早**那条时间，用于整体排序
4. 无时间条的图（微信名片页、转账凭证页、纯图片）会进 `待核对\`，按文件时间排在最后
5. 只处理图片（jpg / png / bmp / webp / tif），PDF 需先转图
6. 不支持手写内容识别、不支持截图旋转校正

## 故障排查

| 现象 | 处理 |
|------|------|
| 提示「未找到 python」 | 安装 Python 并勾选 *Add Python to PATH*，或改用完整路径调用 |
| 提示「Windows OCR 引擎不可用」 | 系统未装中文语言包：设置 → 时间和语言 → 语言 → 添加「中文(简体)」 |
| 提示「禁止运行脚本」 | 直接双击 `排序.bat`（其中已带 `-ExecutionPolicy Bypass`），不要单独右键运行 `.ps1` |
| 大量图进 `待核对` | 截图分辨率过低或时间条被遮挡；重截一张更清晰的，或手动重命名 |
| 排序顺序不对 | 看控制台打印的「图中时间原文」，确认是否读错了时间；也可用 `--dry-run` 先预览再落盘 |
| 输出目录里出现多余旧文件 | 同一天重复运行会把旧结果移入该案文件夹下 `历史\`，不会删除 |

---

## 安全边界

- **只读** `输入` 目录（或 `--input` 指定目录）中的图片
- **只写** `输出` 目录（或 `--output` 指定目录）
- 默认**复制**而非移动，原件不动
- 任何情况下不删除用户文件，旧结果一律移入 `历史\` 保留
